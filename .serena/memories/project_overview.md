textToAudioTTS is a Python and shell based audiobook/TTS pipeline focused on long-form chunked generation on CSC Puhti and Mahti. Core flow: chunk source text, render each chunk with one or more TTS model runners, join chunk WAVs into final audiobook outputs, and sync/monitor outputs. Key paths: library/ for source text, scripts/build_chunked_audiobook.py for chunk/build/join orchestration, scripts/mahti/ for cluster bootstrap and model runners, monitor_tts_progress.sh for live monitoring, local_verify_chunks/ for 2-chunk smoke outputs, outputs/ for synced local finals, RUNNING_STATUS.md for operator notes. Current notable workload is Half of a Yellow Sun with qwen3_faster_clone and vibevoice_realtime.
